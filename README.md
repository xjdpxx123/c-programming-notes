# c-programming-notes

一份面向初学者的 C 语言学习笔记，记录 C 语言基础知识与编程实践过程，涵盖基本语法、流程控制、数组、函数、指针、结构体和文件操作等内容。

## 内容

- C 语言基础：程序结构、数据类型、常量与变量、运算符、表达式、输入与输出等
- 流程控制：if、switch、for、while、do-while、break、continue 等
- 数组与字符串：一维数组、二维数组、字符数组、字符串处理、排序与查找等
- 函数：函数定义与调用、参数传递、递归、变量作用域、多文件编程等
- 指针：指针基础、指针运算、指针与数组、指针与函数等
- 结构体：结构体定义、结构体数组、结构体指针、链表等
- 文件操作：文件打开与关闭、文本与二进制文件读写、文件定位、人员信息管理等
